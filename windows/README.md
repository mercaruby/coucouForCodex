# Windows adaptation

See the [repository README](../README.md) for build, authentication, hook trust and security instructions.

Codex hooks and OpenAI API chat are migrated. ChatGPT session chat is gated by the native CLI's actual protocol schema; npm Codex CLI 0.159.2 currently fails that compatibility check. No credential is needed merely to observe hooks. macOS has not been migrated.

No binaries are distributed. Local builds retain upstream restricted assets for personal use; redistribution requires replacing them or obtaining permission.
